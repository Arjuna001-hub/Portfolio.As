# Tech Portfolio Website

A modern, responsive portfolio website with a tech-themed design, featuring animated backgrounds, project showcases, and interactive elements.

## 🌟 Features

### ✅ Completed Features
- **Tech-Themed Design**: Dark theme with cyberpunk-inspired colors (cyan, magenta, neon green)
- **Animated Background**: Particle effects and grid overlay with smooth animations
- **Responsive Layout**: Mobile-first design that works on all devices
- **Interactive Navigation**: Smooth scrolling with active section highlighting
- **Project Showcase**: Grid layout with hover effects and project details
- **Skills Section**: Animated progress bars for technical skills
- **Contact Form**: Functional contact form with validation and success states
- **Social Links**: Integrated social media and professional links
- **Scroll Animations**: Fade-in effects and parallax scrolling
- **Mobile Navigation**: Hamburger menu for mobile devices

### 🎨 Design Elements
- Modern gradient effects and glassmorphism
- Animated particles and floating elements
- Hover effects and smooth transitions
- Professional typography using Inter font
- Font Awesome icons throughout
- Custom tech-themed avatar

### 📱 Responsive Features
- Mobile-optimized navigation
- Flexible grid layouts
- Touch-friendly interactions
- Optimized for various screen sizes
- Performance-optimized animations

## 🚀 How to Use

1. **View the Portfolio**: Open `index.html` in your web browser
2. **Navigate Sections**: Use the navigation menu or scroll through sections
3. **Explore Projects**: Hover over project cards to see details and links
4. **Contact Form**: Fill out and submit the contact form (simulated)
5. **Mobile View**: Resize your browser or view on mobile devices

## 🎨 Customization

### Colors
Edit the CSS custom properties in `:root`:
```css
:root {
    --primary-color: #00d4ff;    /* Cyan */
    --secondary-color: #ff00ff; /* Magenta */
    --accent-color: #00ff88;    /* Neon Green */
}
```

### Content
- Update personal information in the HTML file

- Modify skill levels in the skills section
